# 002 续跑检查点

`runs` 增加 `run_checkpoints`（每运行一行），保存整批组合筛选的帕累托前沿、
已处理批次位置与配对/限额指纹。应用启动时 `create_all` 会补建该表，现有表与列不改动。

- 续跑沿用原配对明细和原限额：指纹不一致的检查点会被忽略并从头计算。
- 检查点记录产生它的 `attempt`；领取新尝试时校验运行仍由该尝试持有。
- 旧尝试晚到的结果在写入前比较 `attempt` 与运行状态，不满足即丢弃，不覆盖新版。
- 导出先写 `.tmp` 再原子替换；发布失败时保留 `runs.result` 与 `runs.export_file` 的旧版。
